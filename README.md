## 📝 Descrição

Este repositório documenta minha jornada de aprendizado em **Python**, desde os fundamentos da programação até conceitos mais avançados por meio de projetos práticos.

O conteúdo é baseado no curso **Curso de Python 3 do básico ao avançado - com projetos reais**, disponível na **Udemy**, utilizando a versão mais recente do **Python 3**.

---

## 🎯 Objetivos

- Desenvolver a lógica de programação
- Aprender Python de forma estruturada
- Resolver exercícios e desafios
- Criar projetos para colocar os conhecimentos em prática
- Construir uma base sólida para desenvolvimento de software

---

## 📚 Conteúdos Abordados

O repositório será organizado conforme o progresso no curso, incluindo os seguintes módulos:

- Python + VS Code
- Lógica de Programação
- Funções
- Dicionários
- Módulos
- Programação Funcional
- Programação Orientada a Objetos (POO)
- Interfaces Gráficas com PySide6 (Qt)
- Banco de Dados (SQLite e MySQL)
- Django
- Projetos práticos

> 📌 A organização do repositório seguirá as seções do curso, divididas em pastas para facilitar o aprendizado e acompanhar minha evolução.

- **Linguagem:** Python 3
